Visual refinement update for Daeva Sentinel.

- Rebuilt the app as a cleaner dashboard with separate Encounter, Screen and Voice settings.
- New original winged-crystal emblem, matching Windows icons, and refined dark gold/cyan theme.
- Redesigned launcher with a quieter layout and clearer launch/update controls.
- Softer gradient DPS bars, small source badges, and crisp timer tracks in the compact movable overlay.
- Clearer selected navigation, better spacing, and fully themed dropdowns and tabs.
- English and Polish controls remain available. Skill, boss and other game names stay original; voice callouts stay English.
- Hybrid network/OCR, DPS calculations and signed update behavior are unchanged.

Extract the entire launcher ZIP and run **Daeva Sentinel Launcher.exe**. Use **Play voice demo** to try the UI without the game. Screen recognition needs calibration and network parsing needs Npcap.

Existing launchers install this companion update when you click **Launch companion**. Download the new launcher ZIP if you also want the redesigned launcher window and icon.

Boss detection remains experimental: live European Bakarma encounters have not yet been validated. The threat view is not an authoritative aggro meter. No individual jump timing is predicted.
