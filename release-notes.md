First experimental public build of Daeva Sentinel.

- Movable, compact Boss / DPS / Threat overlay with a dark fantasy-inspired style.
- Network events and calibrated, local English screen OCR can work together.
- Duplicate cast announcements are suppressed across the two sources.
- English and Polish interface; game names stay original and voice callouts stay English.
- Bundled English neural voice pack.
- Party DPS from captured damage; separate boss-target indicator and clearly labelled damage-based threat proxy.
- Launcher with signed updates, checksum verification, shared settings and rollback.

Extract the entire launcher ZIP and run **Daeva Sentinel Launcher.exe**. Use **Play voice demo** to try the UI without the game. Screen recognition needs calibration and network parsing needs Npcap.

The release is experimental: live European Bakarma encounters have not yet been validated. The threat view is not an authoritative aggro meter. No individual jump timing is predicted.
